# Mp3Editor

Установка единых данных об авторе, альбоме и изображении для всех музыкальных файлов, находящихся в одной директории.

## Легенда

Если вы, как и я, скачиваете музыку из Telegram, сторонних сайтов и используете обычный MP3-плеер, вы часто сталкивались с проблемой переименования файлов: у многих нет автора, альбома и т. д. Вручную это делать очень долго и муторно, поэтому я написал консольное приложение, которое автоматически устанавливает одинакового автора, альбом и изображение.

## Использование

1. Запустите `dotnet run`.
2. В терминале укажите путь к директории. **Важно:** все файлы, которые вы хотите привести к общему виду, должны лежать в одной директории.
3. Укажите, из какого альбома треки.
4. Укажите автора (или авторов) альбома.
5. Опционально можете указать общее изображение.
